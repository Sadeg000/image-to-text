Image to text and Excel, without uploading anything

Drop a photo, screenshot or scan. Get text, or a table you can paste straight into Excel with every value in its own cell. It all runs in your browser.

Text mode keeps paragraphs and line breaks. Use Table mode for spreadsheets, price lists and schedules.

Private by design. No upload, no account, no limits. The first run downloads the language data once; after that your image is processed only on this device.
Tip: sharp, well-lit images work best. Dark-mode screenshots are fixed automatically. In Table mode, check the numbers once before using them; OCR is never 100% perfect.
