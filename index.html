Image to text and Excel, detected automatically

Upload photos, scans or a PDF. Get text, Excel cells or a Word file. Everything runs in your browser, nothing is uploaded.

The first run downloads language data and can take 10–20 seconds. After that it is much faster. Works with printed text; handwriting is not supported.

✂ Edit pages (optional): rotate or crop

Not needed in most cases. Rotation, margins and page edges are fixed automatically. Use this only if a page still reads badly. Drag on a page to crop it.

Private by design. No upload, no account, no limits. Your files are processed only on this device.
Tip: sharp, well-lit images work best. Check numbers once before using them; OCR is never 100% perfect. The Word file opens in Word, Google Docs and LibreOffice.
